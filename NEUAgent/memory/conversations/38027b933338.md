## 什么是 Redis 集群

**Redis 集群（Redis Cluster）** 是 Redis 官方提供的**分布式部署方案**，旨在实现：

1. **数据自动分片**（Sharding）—— 将数据分散到多个节点
2. **高可用性**（High Availability）—— 部分节点故障时仍可继续服务
3. **水平扩展**（Horizontal Scaling）—— 通过增加节点来提升性能

---

### 核心工作原理

#### 1. 数据分片 —— 16384 个哈希槽

Redis 集群将整个键空间划分为 **16384 个哈希槽（Hash Slot）**，每个节点负责一部分槽位。

CRC16(key) % 16384  →  计算出该 key 属于哪个槽

例如一个 3 节点的集群：

| Node A | 0 – 5460 |
| Node B | 5461 – 10922 |
| Node C | 10923 – 16383 |
